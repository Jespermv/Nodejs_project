# Dummy REST API

This is a Node.js-based dummy REST API for basic CRUD operations.

## Endpoints

- **GET /posts**: Retrieve all posts.
- **POST /posts**: Add a new post.
- **DELETE /posts/:id**: Delete a specific post.
- **PUT /posts/:id**: Update an existing post.
- **GET /posts/generate**: Generate a dummy post.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```
